# v0.4.6

## 本版内容

- 独立找回密码页，登录页精简为找回/注册入口。
- 邮箱验证后注册，管理员指定注册组，注册默认关闭。
- 图文邮件与纯文本兼容版本，站点强调色 Logo 内嵌图片。
- 六类邮件可编辑文案及预览，安全链接由系统固定生成。
- 用户组独立编辑弹窗，保留三种视图、搜索与筛选。

## 数据与安全

迁移 9 仅新增三张邮件/注册表，不覆盖站点配置、SMTP、用户、存储或图片。升级需要后端与前端一起更新。注册用户固定为普通角色，继承指定组策略；链接到期、已消费、注册关闭或组不可用时拒绝创建。

模板只接受纯文本，不接受任意 HTML。邮件图片采用 CID 内嵌 PNG；客户端不显示 HTML 时仍可使用纯文本安全链接。自定义文案只影响新的邮件，SMTP 指纹不变。

## 验证

- `go test ./...` 与邮件 MIME/转义/PNG 测试。
- 授权克隆库连续执行两次迁移，原站点设置、用户、图片和副本指纹不变。
- 克隆库假发信器验证 SMTP 测试门槛、密码重设、邮箱变更、注册、角色/组约束、关闭和停用拦截、令牌重放、队列取消与限流。
- Playwright 模拟 API：390 / 768 / 1440 / 2560 宽度下邮件、独立找回、注册、用户组、账号和存储回归；30 个组、45 个存储位置的三种视图。

没有部署到生产环境，没有发送真实邮件或访问真实云存储。实际邮箱客户端显示与收件箱投递需部署后主动验证。
