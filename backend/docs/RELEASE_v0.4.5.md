# v0.4.5 交付与验证记录

## 本版内容

- SMTP 邮件配置、测试发信、队列记录、取消/重试、固定模板预览。
- 验证邮箱、验证后更换邮箱、一次性密码找回；敏感变更撤销会话及 API Token。
- 后台任务页移除重复的 Local/S3 补齐控制，已有记录及恢复入口保留。
- MySQL 备份复用现有存储，流式写入、私有本地文件权限、并发去重和超时恢复。
- 发布版本统一为 v0.4.5，静态资源缓存版本同步更新。

## 已完成验证

- `go test ./...`、`go vet ./...` 通过。
- 修改的 JavaScript 及浏览器测试脚本语法检查通过。
- Linux amd64 静态二进制构建通过。
- 授权测试库的迁移 8 重复执行通过，既有设置、账号、图片及旧副本指纹未变化。
- 邮件核心集成测试使用假发信器通过：凭据加密、测试后启用、邮箱验证与换绑、密码重设、令牌重复使用拒绝、旧会话失效、统一找回响应、有限重试及配置脱敏。测试临时记录已清理，没有启动真实 SMTP 或生产存储工作器。
- 本地备份单元测试覆盖完整写入、0600 权限、短写拒绝、失败不覆盖已有备份、临时文件清理、路径穿越及取消状态。

## 尚未完成的验收

- 浏览器初测覆盖了邮件配置页多个分辨率，但发现发送记录在 390px 下溢出。已修复网格最小宽度，并补充测试脚本；工具自动审批随后持续发生兼容性异常，最终浏览器全流程未能重新运行，不能视为通过。
- 没有使用真实 SMTP 发信，实际服务商认证、证书与收件箱投递需要管理员主动测试。
- 没有执行真实 mysqldump 到生产 S3 的备份或恢复。上线前请在私有测试存储完成一次完整备份及隔离库恢复演练。
- 建议先在测试环境安装本包，完成上述验收后再部署生产。用户、用户组、存储联动的全面整理留到下一版。

## 升级边界

需部署后端和静态资源，首次启动需要数据库 CREATE/ALTER 权限。迁移仅新增邮件相关结构及会话版本，不重置既有配置。保留 JWT_SECRET、.env、图片和自定义静态资源。具体操作见 README_DEPLOY.md。

本次工作没有修改生产环境、没有更改生产账号，也没有向真实用户发送邮件。
